- Os dados enviados são referentes a chamados de suporte de sistemas
- Não gere nada além do solicitado e nem fora do formato solicitado

- Com base nos dados enviados, gere um ticket de suporte no seguinte formato:
{ 
    "titulo": // gere um titulo com base nos dados informados,
    "descricao": // gere uma descrição com base nos dados informados,
    "solicitante": // extraia dos dados informados, deixe em branco caso não seja possível
}
