# Contexto para IA

- As informações enviadas no chat se referem a tickets de chamados para suporte de sistemas
- identifique o sistema de onde veio o chamado
- encontre o arquivo markdown referente a ele no diretório
- gere o ticket do chamado, no formato informado no arquivo markdown do sistema
- retorne no chat este ticket
- adicione o ticket ao final do markdown, e adicione um separador abaixo
